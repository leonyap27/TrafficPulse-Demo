Assumptions & notes

  • Data source. data/traffic_incidents.json — dummy dataset bundled with the repo. Not real LTA production data.
  • Time horizon. All 30 incidents are within a ~4-hour window on 2026-05-31; the page treats the full set as "recent" without a sliding window.
  • "Active delay" totals sum estimated_delay_min across Active incidents per road; resolved incidents are counted but excluded from delay totals.
  • "Hotspot" definition. Roads ranked by total active delay (minutes), descending. Tie-break: more active incidents wins.
  • Static page. No external APIs, no production data, no build step. The page tries to fetch() the data file; if blocked by file:// origin policy, it falls back to inline JSON below.
  • Sibling page. page1.html (separate ticket) shows the incident-level table; this page (page2.html) is the road-network rollup view.

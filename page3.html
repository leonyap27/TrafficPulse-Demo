Assumptions

  • The dataset is a static snapshot embedded in this page. There is no live refresh and no server call.
  • "Now" is anchored to the latest timestamp in the dataset (—), not wall-clock time, so the page is reproducible for demos.
  • KPI cards are global situational-awareness counts and ignore the time-window chips. Chips only filter the chronological feed and the incident table below the heatmap.
  • "Lanes affected right now" sums lanes across all active incidents; overlapping lanes on the same road are not de-duplicated.
  • Resolved incidents stay visible but are visually de-emphasised so operators can see what just cleared.
  • This is dummy data for demo purposes — not a real LTA feed.
